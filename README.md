# 📊 Visualizzatore dei Risultati – ISW2 A.A. 2024/2025

Questo repository contiene il codice utilizzato per **visualizzare i risultati** prodotti dal progetto principale di Machine Learning per la predizione di classi buggy.  
Il tool genera **boxplot** a partire dai file CSV prodotti da **ACUME**, permettendo di confrontare in modo grafico le performance dei diversi modelli e configurazioni.

---

## 🚀 Uso
1. Inserire nella cartella `src/main/resources` i file CSV generati da ACUME  
2. Eseguire la classe ***CSVProcessor*** per preparare i file CSV alla visualizzazione  
3. Eseguire la classe ***BoxplotVisualizer*** per la generazione dei boxplot
